# Copper Scroll — пробные иконки

Шесть отдельных PNG: три сюжета, каждый в двух вариантах детализации. Созданы 21 октября 2026 года встроенным генератором изображений. Прозрачный фон — настоящий alpha-канал; клетчатый или чёрный фон в файлы не добавлен.

Все исходники квадратные: **1254 × 1254 px, RGBA**. PNG скопированы без изменения пикселей. Это мастер-изображения для сравнения; файлы пока не являются окончательным каталогом production-иконок.

## Как добавить в репозиторий

Распаковать ZIP в корень репозитория: каталог `docs/reference/icons-demo/` должен оказаться внутри проекта CopperScroll. Добавить и отправить в Git все файлы этого каталога. Рабочие ресурсы приложения сейчас заменять не требуется.

Имена `demo_*` — имена пробных файлов, а не окончательные persisted Icon ID. Назначение production ID будет отдельным решением.

## Для последующего задания на демонстрационный экран

- Сравнить каждый сюжет и оба варианта при 48, 54 и 60 dp.
- Размер картинки задавать одинаковым квадратным контейнером, сохраняя пропорции PNG; не растягивать непропорционально и не обрезать содержимое.
- Для сопоставления использовать одинаковые фон, отступы и текст строки.
- Проверить прокрутку списка и светлый фон. Отдельно полезно посмотреть рисунки на более тёмной цветной заливке.
- Предусмотреть подготовку уменьшенных производных для Android, например 256 × 256 px, с сохранением alpha. Мастера из этого каталога сохранить. Уменьшенные версии в этот архив не входят.
- Сцена — статическая демонстрация, без открытия контейнера и без изменения формата данных.

`manifest.json` содержит размеры, объёмы и SHA-256 изображений. `prompts.json` — полные запросы генерации. Более подробные варианты созданы редактированием соответствующих простых вариантов с сохранением основных форм и палитры. Генерация не гарантирует абсолютно одинаковые контуры в паре; образцы предназначены для визуального выбора, а не попиксельного эксперимента.
